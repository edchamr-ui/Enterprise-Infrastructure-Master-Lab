# 1. Purpose

This document records significant project changes throughout the Enterprise Infrastructure Master Lab.

The change log provides traceability for modifications affecting project scope, architecture, technical standards, infrastructure design, implementation strategy or operational procedures.

Minor editorial changes do not require formal entry unless they materially affect the project.

---

# 2. Change Management Principles

All significant project changes should:

* Have a clear reason.
* Identify the affected project area.
* Describe the expected impact.
* Be reviewed before implementation where practical.
* Be reflected in relevant documentation.
* Be committed to Git.
* Preserve alignment with the approved project blueprint.

---

# 3. Change Status

Changes may use the following status values:

* Proposed
* Under Review
* Approved
* Implemented
* Rejected
* Superseded
